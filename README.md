## Descripción del proyecto

Este proyecto corresponde al Lab 2 desarrollado con Django.

La aplicación presenta información sobre artistas representativos del vallenato colombiano y fue adaptada para trabajar con **MongoDB Atlas** mediante **MongoEngine**.

El proyecto implementa las cuatro operaciones CRUD:

- CREATE: crear artistas.
- READ: consultar artistas.
- UPDATE: actualizar artistas.
- DELETE: eliminar artistas.

La conexión, el modelo, la lógica CRUD y las rutas se encuentran separados en diferentes archivos, siguiendo la estructura solicitada en la guía del laboratorio.
